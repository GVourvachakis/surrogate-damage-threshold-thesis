# Compact Thesis Source

On the `compact-thesis` branch, `thesis/thesis.tex` is the compact thesis
root. Run `make thesis` from the repository root to build this variant.

The compact source includes Chapters 1--4 and Appendices A--C. Appendix D is
excluded because it depends on a cross-reference outside the compact source
scope. The public-safe asset policy and omission notices are shared with the
extended thesis on `main`.
